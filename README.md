# AgeWise — Age Calculator (React + Vite)

A responsive age calculator with a soft blue/mint background and a clear interface.

## Features
- Calculates age in years, months, and days using the current date
- Shows days remaining until the next birthday
- Rejects future dates and asks for a date if none is selected
- Reset button clears the form and results
- Responsive layout for desktop and mobile

## Run in VS Code
1. Extract the ZIP and open this folder in VS Code.
2. Open the terminal in this folder.
3. Run `npm install`
4. Run `npm run dev`
5. Open the localhost URL shown by Vite (usually http://localhost:5173).
